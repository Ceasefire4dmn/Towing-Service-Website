**Towing Service Website** - это одностраничный информационный лендинг, написаный на чистых HTML и CSS для ИП в Новороссийке, специализирующегося на эвакуации автомобилей разных категорий. Цель данного лендинга - дать пользователю нужную и наглядную информацию в момент, когда необходимо быстро принять решение. Из-за такой особенности в аудитории сайта дизан был сделан лаконично и минималистично, чтобы не отвлекать внимание пользователя.   
- В мобильной версии сайта, для удобства есть слайдер с карточками - видами транспортных средств для транспортировки. Так необходимая информация компактно и уместно располагается на экране телефона. Слайдер представляет собой анимированное переключение карточек, реализованное с помощью Java Script вкрапления в script-элементе файла "index.html".  
- С помощью CSS на кнопках была реализована ненавязчивая анимация при нажатии.

### Технологии
- Разметка HTML
- Стили и анимация CSS, Java Script
